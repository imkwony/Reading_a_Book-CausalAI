## 왜 필요한가
"약을 먹은 사람의 생존율이 높다"와 "모두에게 약을 먹이면 생존율이 오른다"는 다른 문장이다. 또 "이미 죽은 환자가 그때 약을 먹었다면?"은 또 다른 종류의 문장이다. 이 세 가지를 **하나의 모델에서 정확하게** 구분하려면 변동의 출처(U), 인과 과정(F), 모집단(P(U))을 한꺼번에 적는 언어가 필요하다. 책은 SCM이 기존의 여러 인과 접근을 포괄한다고 설명한다 (p.56).

## 용어 준비
| 용어 | 한 줄 뜻 | 예 |
|---|---|---|
| 외생 변수 U (exogenous) | 모델 밖에서 정해지는 배경 요인 | 환자의 타고난 저항력 |
| 내생 변수 V (endogenous) | 모델 안의 다른 변수들로 정해지는 변수 | 치료 X, 생존 Y |
| 메커니즘 F | 각 변수를 부모와 U로 계산하는 함수 모음 | y ← f(x, u) |
| 부모 pa_i | V_i를 계산할 때 쓰이는 다른 내생 변수 | Y의 부모는 X |
| 서브모델 M_x | X의 메커니즘을 상수 x로 교체한 모델 | 모두에게 약 투여 |
| 잠재결과 Y_x(u) | 개체 u에게 개입 x를 했을 때의 Y 값 | 이 환자가 약을 먹었다면 |
| effectiveness | 개입한 변수는 확률 1로 그 값이 된다는 성질 | do(x)하면 X=x |
| 반 마르코프 (semi-Markovian) | U들이 서로 의존하거나 부모를 공유해도 되는 모델 | 책이 다루는 일반 설정 |

## 개념 1. SCM의 네 부품 (Definition 2.1.1, p.56)
SCM은 네 가지로 이루어진 묶음 M = ⟨U, V, F, P(U)⟩ 이다.
- **U**: 모델 밖에서 정해지는 외생 변수. 환자·학생·고객 같은 개체의 상태를 나타내기도 한다.
- **V**: V₁, …, Vₙ. 다른 변수들로 정해지는 내생 변수.
- **F**: 각 V_i에 대해 v_i ← f_i(pa_i, u_i). 화살표 ←는 '계산해서 대입한다'는 뜻이며, 개입하기 전에는 바뀌지 않는 인과 과정이다.
- **P(U)**: U의 확률분포. 모델 밖 세계의 상태를 요약한다.

책은 V가 유한하고 모델이 재귀적(순환 없음)이라고 가정한다. U들이 독립이면 마르코프, 서로 의존하거나 부모를 공유할 수 있으면 반 마르코프이며, 이 책은 후자까지 다룬다. 모든 모델은 현실의 한 조각이다 (그림 2.2).

![SCM 도식](visual/v3/d3_a_scm.png)

**비유: 보드게임.** 규칙집은 고정돼 있고 주사위가 매번 달라서 말의 위치가 달라진다.

| 비유 | 개념 |
|---|---|
| 규칙집 | F |
| 주사위 눈 | U |
| 주사위의 확률 | P(U) |
| 보드 위 말의 위치 | V |

> **비유의 한계**: 실제 환경에서 U는 보이지 않고 F도 모른다. 책은 SCM을 모르는 채로 어디까지 추론할 수 있는지를 묻는다. 또 규칙을 한 줄 바꾸는 것이 '개입'이라는 점은 비유와 잘 맞지만, 현실의 개입이 규칙을 정확히 한 줄만 바꾼다는 보장은 모델링 가정이다.

### 두 예제
**예 2.1 (주사위, p.57)**: U₁, U₂는 각각 1~6이 확률 1/6. X ← U₁ + U₂, Y ← U₁ − U₂. 두 주사위를 굴리고 합 X와 차 Y만 관측한다. Val(X)={2..12}, Val(Y)={−5..5}.

**예 2.2 (의학, p.57)**: V = {X 약, Y 생존, Z 증상}, U = {U_r 저항력, U_x, U_y, U_z}. 저항력이 있으면 약과 무관하게 살기 쉽고, 증상이 있으면 의사가 약을 처방하며, 약은 저항력 있는 환자에게 도움이 되고 없는 환자에게는 해롭다. 확률은 P(U_r=1)=0.25, P(U_z=1)=0.95, P(U_x=1)=0.9, P(U_y=1)=0.7. 외생 상태가 2⁴ = 16가지이며 표 2.2가 각 상태의 V 값과 확률을 보여 준다.

## 개념 2. Layer 1 — 보기 (Definition 2.2.1, p.58)
SCM은 V의 결합 분포 P_M(V)를 정한다. 절차는 두 단계다.
1. 각 개체 U=u에 대해 Nature가 F를 올바른 순서(오른쪽에 쓰인 변수가 먼저)로 평가한다.
2. 사건 Y=y와 일치하는 모든 u의 확률 P(u)를 더한다.

**주사위 예**: U=(1,1)이면 X=2, Y=0이다. 이 값을 만드는 u는 그 조합뿐이므로 P(X=2, Y=0) = 1/36. Y=0이 되는 조합은 (k,k) 여섯 개라 P(Y=0)=1/6. 그런데 X=2를 알면 P(Y=0∣X=2)=1이다. 합이 2이면 차는 반드시 0이므로 X와 Y는 결정적으로 연결된다.

**의학 예 (예 2.3)**: 표 2.2에서 X=1인 행의 확률 합은 0.29이고 그중 Y=1인 행은 0.215이다. 따라서 P(Y=1∣X=1) = 0.215/0.29 = 0.7414, P(Y=1∣X=0)=0.3197, P(Z=1)=0.2375이다. 약을 먹은 쪽의 생존이 높아 보인다.

## 개념 3. Layer 2 — 하기 (Definition 2.2.2–2.2.5, p.60–61)
**서브모델 (Def 2.2.2)**: 변수 집합 X를 값 x로 고정하는 개입은 F_x = {f_i : V_i ∉ X} ∪ {X ← x} 로 모델링한다. X의 원래 메커니즘이 상수로 교체되고 P(U)는 그대로다.

![서브모델](visual/v3/d3_c_submodel.png)

**잠재결과 (Def 2.2.3)**: 개체 u에 대해 Y_x(u)는 서브모델 M_x에서 Y(u)를 계산한 값이다. 확률적으로는 P(U)에 대해 평균한 확률변수 Y_x가 된다. 평균 인과 효과는 E(Y_{X=1}) − E(Y_{X=0}) 로 쓴다.

**L2 평가 (Def 2.2.4)**: P(y_x) = ∑_u 1(Y_x(u)=y)P(u). 이 분포를 P(Y∣do(x))로도 쓴다. 조건이 붙으면 do(x)는 식 전체에 걸린다 (식 2.9).

**Effectiveness (Def 2.2.5)**: do(x) 아래에서 개입한 변수는 확률 1로 x가 된다. 자연스러운 변동의 출처(부모, U_x)와 끊겼기 때문이다. 이 때문에 개입으로 생기는 변화는 반드시 '인과적'이다.

**예 2.4 (주사위)**: 관찰자가 합을 2라고 허위 보고하는 것은 F_{X=2} = {X ← 2, Y ← U₁−U₂} 이다. 차는 그대로이므로 P(Y=0∣do(X=2)) = P(Y=0) = 1/6. 관측 P(Y=0∣X=2)=1과 다르며, X는 Y에 인과 효과가 없다.

**예 2.5 (의학)**: 공공보건 당국이 증상과 무관하게 모두에게 약을 준다. U_r=1이면 Y_{X=1}(u)=1이므로 P(Y=1∣do(X=1)) = P(U_r=1) = 0.25, P(Y=1∣do(X=0))=0.4이다. L1의 차이는 양수(+0.43, 아래 참고)지만 L2의 차이는 −0.15로 약이 평균적으로 해롭다. 의사들은 증상이 있는 환자(저항력 있는 쪽이 많음)에게만 약을 처방했기 때문에 관측 비교가 왜곡된 것이다.

![보기와 하기의 반전](visual/v3/d3_d_flip.png)

> **책의 숫자 메모**: 식 2.16은 0.43이라고 쓰지만 같은 책의 값 0.7414 − 0.3197은 0.4217 ≈ 0.42다. 직접 16행 표로 다시 계산해도 0.42다. 부호와 결론에는 영향이 없다.

## 개념 4. Layer 3 — 상상하기 (Definition 2.2.6, p.63)
L3 분포는 서로 다른 아래첨자가 한 식에 함께 있는 확률 P(y_x, …, z_w) 이다. 절차는 다음과 같다.
1. 각 아래첨자에 해당하는 메커니즘을 교체해 F_x, …, F_w를 만든다.
2. **같은 u**에 대해 각 세계의 Nature가 수정된 메커니즘을 평가한다.
3. 모든 조건을 동시에 만족하는 u의 P(u)를 더한다.

**예 2.6**: 약 없이 사망한 환자(X=0, Y=0)가 약을 받았다면 살았을까.

P(Y_{X=1}=1 ∣ X=0, Y=0) = (0.003375+0.007125) / (0.023625+0.448875+0.003375+0.007125) = 0.0105/0.483 ≈ **0.0217**

분모는 한 세계(사실 세계)의 확률이라 L1이다. 분자는 사실 세계(X=0, Y=0)와 개입 세계(Y_{X=1}=1)를 동시에 보므로 L1·L2의 언어로는 쓸 수 없다. 이 환자들은 되살려 다른 조건으로 실험할 수 없으므로 실험으로도 직접 얻을 수 없다. 반면 P(Y_{X=1}=1 ∣ X=0, Y=1) = 0.1079 이므로 약 없이 살아남은 사람의 약 90%는 약을 먹었다면 죽었을 것이다. 의사들은 이득을 볼 환자에게만 처방했던 셈이다.

![세 층 한눈에](visual/v3/d3_e_pipeline.png)

**L3의 다른 양 (p.65)**: 필요 확률 PN = P(y′_{x′}∣x,y), 충분 확률 PS = P(y_x∣x′,y′), 둘의 결합인 PNS = P(y_x, y′_{x′}), 중첩 반사실 Y_{x,M_{x′}}(간접 효과 정의에 쓰임). 책임 소재·공정성·설명에 쓰인다.

**층의 요약 (표 2.1)**
| 층 | 활동 | 질문 | 예 | ML 과제 |
|---|---|---|---|---|
| L1 P(y∣x) | 보기 | 무엇인가? | 증상은 병에 대해 무엇을 알려 주나 | 지도·비지도 학습 |
| L2 P(y∣do(x),c) | 하기 | 만약 ~하면? | 아스피린을 먹으면 두통이 나을까 | 강화학습 |
| L3 P(y_x∣x′,y′) | 상상하기 | 왜? | 두통이 나은 건 아스피린 때문이었나 | (현재 AI의 큰 도전) |

## 수식 풀이
**① L1 (식 2.4)**: P(y) = ∑_u 1(Y(u)=y) P(u)
- P(y): Y가 y일 확률, Y(u): 외생 상태 u에서 F를 평가한 값, 1(·): 참이면 1 아니면 0, ∑_u: 모든 외생 상태 합.
- 말로: Y=y가 되는 u의 확률을 전부 모은다.

**② L2 (식 2.8)**: P(y_x) = ∑_u 1(Y_x(u)=y) P(u)
- ①에서 Y(u)를 서브모델의 Y_x(u)로 바꾼 것뿐이다. P(u)는 그대로다.

**③ L3 (식 2.18)**: P(y_x, …, z_w) = ∑_u 1(Y_x(u)=y, …, Z_w(u)=z) P(u)
- 한 u에서 여러 세계의 결과를 동시에 보고, 모든 조건을 만족할 때만 더한다.

**④ 조건부 반사실 (식 2.20–2.23)**: P(Y_{X=1}=1∣X=0,Y=0) = 분자 / 분모, 분자는 표의 11·13행, 분모는 4·8·11·13행.

## 흔한 오해
- ❌ "U는 그냥 잡음이다" → ✅ U는 개체와 모집단의 변동을 담는다. 반사실은 같은 u를 여러 세계에서 평가하는 것이다.
- ❌ "P(Y∣X)와 P(Y∣do(X))는 같은 값이다" → ✅ 예 2.5에서 부호가 반대다.
- ❌ "반사실은 실험으로 확인하면 된다" → ✅ 한 개체가 두 세계를 동시에 살 수 없다. L2 자료로도 부족하다.
- ❌ "SCM이 있어야 L1을 알 수 있다" → ✅ SCM이 주어지면 세 층이 모두 정의되지만 에이전트는 보통 SCM을 모른다. 데이터는 L1 분포 일부만 준다.

## 정리
1. SCM = ⟨U, V, F, P(U)⟩. 외생 U와 메커니즘 F가 관측 V를 만든다.
2. L1은 F를 그대로 평가, L2는 메커니즘을 상수로 교체(do), L3는 여러 세계를 동시에 평가한다.
3. 보기와 하기는 다른 답을 낼 수 있고, 반사실은 어떤 실험으로도 직접 얻을 수 없다.
4. 다음 날(Day 4)은 이 세 층이 서로 환원되지 않는다는 정리(CHT)를 읽는다.
