예 2.7: 세 개의 SCM, 같은 관측 분포X: 치료, Y: 회복. U₁, U₂는 공정한 이진 동전 (각 확률 1/2)
M∗
X ← U₁
Y ← U₂

X는 Y와 무관

M
X ← 1(U₁ = U₂)
Y ← U₁ + 1(X=1, U₁=0, U₂=1)

Y가 X에 의존

M′
X ← U₁
Y ← X·U₂ + (1−X)(1−U₂)

Y가 X에 의존

질문M∗MM′
L₁ P(X, Y) (4칸 모두)1/41/41/4
L₂ P(Y=1 ∣ do(X=1))1/23/41/2
L₃ P(YX=0=1 ∣ X=1, Y=0)00 (직접 계산)1
M∗과 M은 L₁이 같지만 L₂가 다르고, M∗과 M′은 L₁·L₂가 같지만 L₃가 정반대다
