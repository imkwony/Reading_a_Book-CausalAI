세 가지 기본 패턴: 흐름은 언제 열리고 닫히나Z를 모를 때(왼쪽)와 Z를 관측했을 때(오른쪽, 네모 = 조건부)의 X와 Y의 관계 — Fig. 2.15

체인

X → Z → Y (Z는 매개)

의존

흐름이 열려 있다: X를 알면 Y를 더 잘 맞힌다

독립

Z를 알면 X의 정보가 이미 Z에 담겨 있어 막힌다

포크 (공통 원인)

X ← Z → Y (Z는 원인)

의존

같은 Z에서 갈라져 나와 서로 상관을 보인다

독립

Z를 고정하면 공통 원인의 영향이 사라진다

콜라이더 (공통 결과)

X → Z ← Y (Z는 결과)

독립

원인이 서로 무관하므로 기본적으로 막혀 있다

의존

Z(또는 후손)를 알면 막힌 길이 열린다

체인·포크는 기본이 '열림'이고 Z가 닫는다. 콜라이더는 기본이 '닫힘'이고 Z(또는 후손)의 관측이 연다
