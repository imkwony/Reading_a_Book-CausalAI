d-분리 직접 해 보기: 기후(C), 스프링클러(S), 비(R), 젖음(W), 미끄러움(L)Fig. 2.16 — 경로를 모두 나열하고 삼조별로 막힘을 확인한다 (예 2.15, 2.16)

예 2.15 · S와 W가 d-분리인가? (Z = ∅)

p1 S → W : 길이 2, 막을 수 없다 열림

p2 S ← C → R → W : 포크, 체인 모두 Z에 없어 열림

→ 열린 경로가 있으므로 d-연결

Z = {R}이어도 p2만 막히고 p1은 남아 d-연결

예 2.16 · R과 L이 d-분리인가? (Z = {W})

p1 R → W → L : 체인의 가운데 W ∈ Z 막힘

p2 R ← C → S → W → L : 마지막 삼조 S → W → L 이 W ∈ Z 로 막힘

→ 모든 경로가 막혀 d-분리

W는 S→W→L에서는 체인, S→W←R에서는 콜라이더

W를 조건으로 걸면 S와 L의 경로는 막히지만, S와 R 사이는 콜라이더가 열려 오히려 의존이 생긴다
