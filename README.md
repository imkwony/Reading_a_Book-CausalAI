# Reading a Book: Causal AI

『Causal Artificial Intelligence』를 읽으며 만든 수업·학습 자료 모음입니다.

이 책을 활용해 수업 자료를 제작하고 있습니다.

- https://causalai.net/
- https://causalai-book.net/

## 구성

날짜별 폴더(`day01` ~ )마다 같은 형태의 자료가 들어 있습니다.

| 파일 | 설명 |
|---|---|
| `dayNN.pptx` | 그날 범위를 설명하는 슬라이드 |
| `dayNN.md` | 슬라이드의 마크다운 원본 |
| `dayNN_note.md` | 혼자 읽고 복습하는 학습 노트 (비유, 용어 풀이, 흔한 오해, 퀴즈와 해설) |
| `visual/` | 슬라이드에 쓴 도식(HTML, PNG) |

쪽수는 PDF 쪽 기준이며, 인쇄 쪽수는 PDF 쪽 − 12입니다.

## 참고

- 이 저장소에는 책 PDF나 책 본문을 옮긴 텍스트를 올리지 않습니다. 모든 자료는 책의 내용을 풀어서 다시 쓴 것입니다.
- 책에 없는 예시를 직접 만들어 넣은 곳은 슬라이드와 노트에 "책의 예가 아님"으로 표시했습니다.
