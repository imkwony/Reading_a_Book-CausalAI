스프링클러 예 (예 4.3): 보는 것과 하는 것의 차이계절(Se) → 스프링클러(Sp), 비(Ra) → 젖음(We) (미끄러움 Sl은 도식에서 생략)
인과 다이어그램 G

━ p1 직접 경로 Sp→We · ┄ p2 뒷문 경로 Sp←Se→Ra→We

Q1 · 보았을 때 P(We∣Sp=on)
= Σse,ra P(we∣on,ra) P(on∣se) P(ra∣se) P(se) / Σse P(on∣se) P(se)

스프링클러가 켜진 것을 보면 계절도 추론된다 → 비 확률도 바뀜. 비공식적으로 p1 + p2

Q2 · 했을 때 P(We∣do(Sp=on))
= Σse,ra P(we∣on,ra) P(ra∣se) P(se)

내가 켜면 Se→Sp 연결이 끊겨 계절 추론 경로가 사라진다. 비공식적으로 p1만

Q1과 Q2의 차이 = Sp→We를 제외한 우회 경로 p2가 만드는 값 = 교란(confounding) 편향
